# Shopping list and budget

The shopping list is generated by the application (**Shopping** page) from your greenhouse configuration and the Planner inputs, so it always matches the current design. Export it as CSV, Excel or PDF from that page; the exports are the authoritative list. This file explains the rules.

## What the list contains

Essential, recommended and optional hardware, spares, consumables, tools and installation materials, filtered into three configurations: **low**, **recommended**, **professional**. Hardware protection (e-stop, float switches, fuses, RCD) is in every tier.

Each line shows: name, specification, quantity and how it was derived, alternatives, compatibility notes, supplier offers, price status, total, and a purchased tick-box.

## Quantities

Calculated only from inputs you supplied. When something required is missing (greenhouse height, fan airflow, target air changes, dripper data, pump flow, loads...) the quantity shows **?** with the missing inputs named. Heuristic counts (climate stations per area, probes per zone, manifold outlets, dosing channels) are labelled assumptions and editable.

## Prices, links, stock

The application **never generates** a price, URL, specification or availability. A price exists only when an *offer* has been recorded, either by you or when it was read from a supplier page with the date noted:

| Status | Meaning |
|---|---|
| verified | read from the live supplier page; date recorded; still re-check before ordering |
| your estimate | entered by you, not checked against a page |
| requires verification | no price known; not included in totals |

Totals include only priced lines and say how many lines are unpriced. VAT: prices quoted without VAT are converted with the VAT rate in Planner options (default 21%, an assumption to verify).

## Suppliers
